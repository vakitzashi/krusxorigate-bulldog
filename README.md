# БУЛЬДОГ KURS — BeGet deployment

Проект подготовлен для статического размещения на BeGet.

## Структура

- `public_html/` — публичный сайт. Внутри только файлы, без вложенных папок.
- `secret/` — будущие закрытые конфигурации и ключи. Содержимое этой папки игнорируется Git и никогда не должно загружаться в `public_html`.

## Деплой

Загрузите **содержимое** папки `public_html` в публичную директорию домена на BeGet. Не загружайте саму папку `public_html` как вложенную директорию.

Стартовая страница — `index.html`. Политика конфиденциальности и оферта находятся рядом с ней. Все изображения, документы, стили и скрипты используют плоские относительные пути.
