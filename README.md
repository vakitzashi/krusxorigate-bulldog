# БУЛЬДОГ KURS

Проект подготовлен для размещения на BeGet.

## Структура

- `public_html/` — публичный сайт. Внутри только файлы, без вложенных папок.
- `secret/` — закрытые конфигурации, ключи и локальная база заказов. Содержимое не попадает в Git и не публикуется через веб-сервер.

Стартовая страница — `index.html`. Политика конфиденциальности и оферта находятся рядом с ней. Все изображения, документы, стили и скрипты используют плоские относительные пути.

## Заказы

Форма отправляет заказ в `public_html/order.php`. Сервер сам назначает номер, фиксирует статус `Новый`, товар, SKU и цену, сохраняет заказ в `secret/orders.sqlite3`, добавляет строку на лист `Заказы` в Google Sheets через Apps Script и отправляет уведомление в Telegram.

Поле `№ товара` намеренно отсутствует. Таблица содержит ровно 15 колонок, заданных в `backend-smoke-test.php`.

Закрытая настройка хранится в `secret/order-config.php` по образцу `order-config.example.php`. Код Google Web App находится в `google-apps-script.example.gs`; рабочая копия с секретом — в игнорируемом Git файле `secret/google-apps-script.gs`. Скрипт разворачивается от владельца таблицы с доступом `Anyone`, а длинный `webhook_secret` защищает запись от посторонних запросов. Саму таблицу можно закрыть для всех и оставить доступ только приглашённым пользователям.

Проверка синтаксиса, структуры таблицы, расчёта скидки, внутренней нумерации и шаблона Telegram выполняется командой `php backend-smoke-test.php`.
